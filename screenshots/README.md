# Screenshots Directory

Please add your application screenshots here:

- `dark-theme.png` - Screenshot of the application in dark theme
- `light-theme.png` - Screenshot of the application in light theme

## Recommended Screenshot Settings

- **Resolution**: 1920x1080 or higher
- **Format**: PNG (for best quality)
- **Content**: Show the full application window with all widgets visible
- **Battery Level**: Around 70-90% for better visual representation
- **Data**: Ensure the historical chart has some data points

## How to Take Screenshots

1. Launch the application:

   ```bash
   sudo python3 main.py
   ```

2. Wait a few minutes for the historical chart to populate with data

3. Take a screenshot:

   - **GNOME**: Press `PrtScn` or use Screenshot tool
   - **KDE**: Press `PrtScn` or use Spectacle
   - **XFCE**: Press `PrtScn` or use xfce4-screenshooter

4. Save the screenshots in this directory with the appropriate names

5. Dark theme screenshot: Use default dark theme
6. Light theme screenshot: Click "☀️ Light Theme" button, then take screenshot
